Colour palette

Four semantic families × four roles, each defined as a light-dark() pair in src/theme/_root.scss with --*-light / --*-dark override hooks. A site configures its own palette, fonts, and patterns via the Themes control panel (color_groups), which themeStyleSheet() bridges back onto these tokens and --colorgroup-{id}-*. [data-theme="high-contrast"] forces high-contrast black/white surfaces with #fff333 links.

Links & content types

Shipped CSS links read --primary-accent-color (5.02 light / 9.14 dark). However, themeStyleSheet() in src/helpers/themeStyles.ts currently defaults --link-foreground-color to var(--accent-color) whenever a site defines color_groups (1.51 light / 1.53 dark on primary ground — see GAPS.md).

Every shipped semantic pairing in _root.scss (matching DEFAULT_COLOR_GROUPS) clears WCAG AA (≥ 4.68:1 across both light and dark modes), and cross-family ground/high-ground combinations (primary on neutral, neutral on primary) clear AAA for body copy. Footer titles and --social-network-icon-color-* map to var(--footer-foreground, #ffffff), which now follows dark ink (#1d2129) on the cool-gray secondary surface (#eceff3) in light mode. Every value here is a default replaced when an editor configures a site theme in the control panel.
