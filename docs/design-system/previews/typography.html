Scalar overrides

Font stacks

All four tokens resolve to the same stack — the theme ships no brand typeface.

--font-sanssystem-ui, sans-serif
--font-bodysystem-ui, sans-serif
--custom-fontsystem-ui, sans-serif
--custom-main-fontsystem-ui, sans-serif — drives upstream $page-font
2xs is the one real gap — it has a font-size but no line-height, so map-get($line-heights, 2xs) returns null. --custom-main-font has no consumer in this package but is read twice by upstream VLT, where it drives $page-font. See GAPS.md §2.6 and §2.7.
