Main Image block

Renders the page's preview_image_link at one of four alignments and three sizes. Its stylesheet references no colour token at all — only the three container widths — so it is unaffected by the block theme.

Variations

Defaultalign: center
Full, with captionalign: full, title and description
Left, smallalign: left, size: s
Right, mediumalign: right, size: m
Centre, overlaid captionalign: center, size: l
Captured from the built Storybook, not hand-written: each block is the real component output with its computed styles inlined, rendered through the withTheme decorator so the colour mode and the --theme-* mapping resolve exactly as they do on a page. Remote photography is replaced by a neutral placeholder. See GAPS.md §7 for why the decorator has to set the colour scheme in two places.
