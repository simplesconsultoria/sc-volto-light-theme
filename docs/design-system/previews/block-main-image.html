Main Image block

Renders the page’s preview_image_link with unified _image.scss alignment, sizing, float, and border support. MainImageSchema offers left, right, and center alignments (full remains a legacy fallback in Layout.tsx); borders in _borders.scss target the img while keeping figcaption outside.
