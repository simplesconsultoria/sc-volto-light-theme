Main Image block

Renders the page’s preview_image_link with unified _image.scss alignment, sizing, float, and border support. MainImageSchema offers left, right, and center alignments (full remains a legacy fallback in Layout.tsx); borders in _borders.scss target the img while keeping figcaption outside.

Border override on image--cardBorderWidth, --cardBorderColor
Generated by make design-previews from the Storybook build. Blocks are rendered through StyledBlock / RenderBlocks with computed styles and CSS pseudo-elements (::before/::after) materialised. Remote and local photography is replaced by a neutral SVG placeholder. Light and dark stages follow the colorMode toolbar global.
