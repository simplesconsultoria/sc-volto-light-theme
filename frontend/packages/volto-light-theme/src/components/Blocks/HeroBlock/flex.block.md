---
block: heroBlock
variation: flex
---

Places the text and the image side by side, with the image on the side chosen by `textSide` and the width of the image set by `imageSize`. Use it for a decorative highlight.

The variation is the default. A block without `variation` is shown as `flex`.

### Examples

```json
{
  "@type": "heroBlock",
  "variation": "flex",
  "href": [{ "@id": "/path/to/item" }]
}
```
